# Wine Not – sito one-page Uva Bot

Sito one-page in italiano per Wine Not: presenta Uva Bot, il sistema di erogazione e conservazione del vino al calice per enoteche, wine bar e ristoranti, e raccoglie richieste di preventivo.

## Struttura
- `index.html`: tutto il sito (HTML, CSS e JavaScript inclusi, immagini incorporate). Nessuna dipendenza oltre ai Google Fonts.

## Personalizzazione
Colori, raggi e spaziature sono variabili CSS all'inizio del file (`:root`).

## Da completare
- Specifiche di Uva Bot nella tabella (`[DA SOSTITUIRE]`)
- Dati aziendali nel footer (ragione sociale, P.IVA, indirizzo, email, telefono)
- Collegare l'invio del modulo a un servizio (email, CRM o endpoint)
- Pagine privacy e cookie (i link puntano a `#`) ed eventuale banner cookie
- Foto del prodotto e delle hero: verificare licenza e diritti d'uso

## Pubblicazione
Il sito è statico: basta ospitare `index.html` (per esempio con GitHub Pages).
